# The entire Python dependency graph of this plugin.

# ONE package, and that is a license control, not a minimalism aesthetic.
# `pnpm licenses:check` walks node_modules and structurally cannot see a
# Python dependency tree, so the guard for this side of the repo is that the
# tree is small enough for a human to have read: `websockets` is
# BSD-3-Clause, it has no dependencies of its own, and an arch row
# (test/arch.spec.ts, S7 Sc7 (e)) fails the build if a second line ever
# appears here. Adding one is a license review, not an edit.
#
# Pinned by version AND by artifact hash. A version pin still trusts whatever
# the index happens to serve under that name; `pip install --require-hashes`
# in .github/workflows/ci-python.yml refuses anything whose SHA-256 is not
# below. The version matches the pin Hermes itself carries, so a plugin
# installed into a Hermes environment never forces a resolver decision.
#
# The hashes are the sdist, the pure-Python wheel, and the CPython 3.12
# wheels for the two platforms this is built and tested on (macOS arm64 and
# x86_64, Linux x86_64 and aarch64). One logical requirement, one line.
