Install

Two routes in, Homebrew or the disk image. Both land the same unsigned build, and this page says exactly what unsigned costs you before you find out on your own.

What you need

  • A Mac running macOS 15 (Sequoia) or later, on Apple silicon.
  • Messages signed in with your Apple ID, with at least one conversation in it.
  • An agent to talk to. WeMessage ships adapters for several and a protocol for the rest, and it installs fine before you have picked one.

Homebrew

The short route. The cask installs the app and leaves the background service to you.

brew tap raybman/wemessage
brew install --cask wemessage

Or the disk image

Download the DMG from the releases page, open it, and drag WeMessage to Applications.

That link is the releases list, on purpose. It is right today, it is right after the next tag, and it still resolves while the newest thing published is a release candidate. A link to a file with a version in its name is wrong one release later and nobody ever edits it.

The builds are unsigned, on purpose

Shipping a signed build requires a paid Apple Developer membership. Putting a yearly fee between you and a working copy of a program whose source you can already read would defeat the point. The cost is one extra step the first time you open it, and it is worth knowing exactly what that step is rather than being told to click through a warning.

  1. Open the DMG and drag WeMessage to Applications.
  2. Launch it. macOS refuses, because it cannot check the app with Apple.
  3. Open System Settings, Privacy and Security, scroll to the bottom, and click Open Anyway next to the message about WeMessage.
  4. Launch it again and confirm.

Right-clicking and choosing Open stopped working for unsigned apps in Sequoia, so Open Anyway in System Settings is the flow, not a fallback for it. If you prefer the command line, the same decision looks like this:

xattr -d com.apple.quarantine /Applications/WeMessage.app

Either way you are vouching for this build yourself instead of asking Apple to vouch for it. So check what you actually downloaded. Every release publishes a SHA256SUMS file next to the artifacts:

shasum -a 256 -c SHA256SUMS

The cost you did not expect is the second one. The Gatekeeper prompt happens once and announces itself. Full Disk Access quietly re-locks after every update, because macOS matches an unsigned app by a hash of its binary and that hash moves on every build. The permissions page is where that is written down, and it is worth reading before your first update rather than after it.

Build it yourself instead

If you would rather not trust a binary at all, the repository builds an ad-hoc bundle with three commands:

pnpm install --frozen-lockfile
pnpm build
pnpm pack:adhoc

The suite is the specification. pnpm test runs it, and it is the same suite CI runs on the artifact you would have downloaded.
