# skills/claude

`SKILL.md` is the skill document a Claude host loads. It is not advice: the three
`<!-- wemessage:* -->` blocks in it are parsed by the test suite and by a scripted
agent, so a verb that moves between blocks changes what that agent does.

`DRYRUN.md` is the evidence. It is a stabilised transcript of that scripted agent
obeying `SKILL.md` against a real daemon, generated by
`packages/daemon/test/skill-dryrun-live.spec.ts`. Regenerate it with:

```
WEMESSAGE_WRITE_DRYRUN=1 npx vitest run --project daemon skill-dryrun-live
```

The suite always compares the transcript it just produced against the committed
file; the environment variable only controls whether it is rewritten. A diff here
means the documented behaviour changed and somebody should look at why.

Verification tier is declared as a value in
`packages/cli/test/helpers/skill-verification.ts`, and the banner at the top of
`SKILL.md` is rendered from it rather than typed.
